## 📖 About the Project (In Simple Words)

**SMART Notes** is a website made for **diploma students preparing for the DDCET exam**.

**What is DDCET?**
The Diploma to Degree Common Entrance Test is an entrance exam that diploma holders take to get admission into degree engineering courses.

Students often struggle to find good study material in one place, and it is hard to stay focused when studying online. SMART Notes solves both problems:

- 📘 **Study material for every DDCET subject**, all in one place, with no distractions.
- ✍️ **A community space** where students write their own notes and blogs, and read what other students have written.

---

## 🧑‍🎓 How It Works (Step by Step)

```
Register  →  Login  →  Dashboard  →  Study Subjects / Write Notes / Read Others' Blogs
```

1. **Register** – Create your account. Your phone number is verified with a secure **OTP**.
2. **Login** – Sign in with your username and password.
3. **Dashboard** – See a clean, modern home screen with everything in one place.
4. **Study** – Open any subject page and read or download its PDF study material.
5. **Write** – Create your own note or blog using the built-in text editor.
6. **Read & Engage** – Read blogs written by other students, **like** the ones you enjoy and **comment** on them.
7. **Get Help** – Use the About Us, Contact Us and Team pages if you face any issue.

## ✨ Features

### 📚 For Studying (DDCET Preparation)
- Subject-wise PDF study materials, covering the DDCET syllabus
- Subjects include **Physics, Maths, Chemistry, Soft Skills, Computers** and more
- Material and content available **from DDCET 2021 onward**
- Simple, distraction-free reading experience so you can focus

### ✍️ For Writing & Sharing (Community Blogs)
- Write your own blog or note with a **rich text editor**:
  - Change **font style**
  - Change **font size**
  - Use **headings** of different sizes
  - **Upload and style images**
- Example: write about your city and add photos to make it interesting
- **Every user can read every other user's blogs at any time**
- ❤️ **Like** a blog you really enjoyed
- 💬 **Comment** to share your opinion or ask questions

### 🔐 Security & Access
- Registration and login system
- **OTP authentication** using Firebase
- **Role-based access control**: normal users can study, write and read, while **administrators have full control** over the platform's content

### ℹ️ Support Pages
- About Us
- Contact Us
- Team Members

## ⚙️ Installation & Setup

### 1. Prerequisites
- A modern web browser (Chrome, Edge, Firefox)
- [Node.js](https://nodejs.org/) (only if your project has a backend server)
- A [MongoDB](https://www.mongodb.com/) database (local or MongoDB Atlas)
- A [Firebase](https://firebase.google.com/) project with **Phone Authentication** enabled

### 2. Clone the repository
```bash
git clone https://github.com/LakshJasoliya/Smart-Notes.git
cd Smart-Notes
```

### 3. Configure Firebase
1. Go to the Firebase Console and create a project.
2. Enable **Authentication → Sign-in method → Phone**.
3. Copy your Firebase config and paste it into the project's Firebase config file.

### 4. Configure MongoDB
Add your MongoDB connection string to the project's configuration file.

### 5. Run the project
- For a static site: open `index.html` in your browser.
- With a backend server:
```bash
npm install
npm start
```
